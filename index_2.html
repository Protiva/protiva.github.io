My research spans natural language processing, human-computer interaction, and clinical data pipelines applied to infectious disease and cancer. Selected Publications

Automated curation of checkpoint inhibitor side-effects from EHR

Protiva Rahman, Cheng Ye, Kathleen Mittendorf, Michele LeNoue-Newton, Christine Micheel, Jan Wolber, Travis Osterman, Daniel Fabbri

JAMIA 2023

Data pipelines for extracting EHR notes related to CPI-induced colitis, achieving 84% precision and reducing note review load by 75%. Predictive models require structured data that diagnosis codes and keyword search alone cannot reliably provide.

PDF Poster NLP · EHR

Semi-automated data curation from biomedical literature

Protiva Rahman, Rachel Xiang, Yihua Wang, Joshua Beckman, Quinn Wells, Iris Jaffe, Megan Shuey, Daniel Fabbri

AMIA 2022

A tool using NLP to auto-populate web forms for biomedical literature curation; 70% accuracy on categorical fields and 49% faster task completion than manual curation.

PDF NLP · Literature

Amplifying domain expertise in clinical data pipelines

Protiva Rahman, Arnab Nandi, Courtney Hebert

JMIR Medical Informatics 2020

A framework for incorporating domain expert feedback at every stage of the clinical data pipeline — from collection through cleaning to analysis — with a case study on antimicrobial susceptibility data.

PDF HCI · Data pipelines

Evaluating interactive data systems

Protiva Rahman, Lilong Jiang, Arnab Nandi

VLDB Journal 2020

A survey of interactive workload characteristics, confounding factors in user studies, and popular evaluation metrics, motivating behavior-driven evaluation for interactive interfaces.

PDF Slides GitHub HCI · Survey

TRANSFORMER: Database-driven form generation for constrained interaction

Protiva Rahman, Arnab Nandi

ACM IUI 2019 · acceptance rate 25%

A system that leverages database contents to optimize form UI widgets and layout for constrained input settings, achieving up to 50–57% reduction in form completion time on smartphones and smartwatches.

PDF Slides HCI · Forms

ICARUS: Minimizing human effort in iterative data completion

Protiva Rahman, Courtney Hebert, Arnab Nandi

VLDB 2018 · acceptance rate 17%

An interactive data completion system that shows users useful subsets for edits and generalizes single edits to multiple cells via suggested rules, used to complete microbiology datasets at OSU Biomedical Informatics.

PDF Website Data systems

Exploratory visualizations of rules for validation of expert decisions

Protiva Rahman, Jian Chen, Courtney Hebert, Preeti Pancholi, Mark Lustberg, Kurt Stevenson, Arnab Nandi

DSIA workshop at IEEE VIS 2018

An interactive visualization for exploring relationships between rules — conflicts and redundancies — and resolving them with expert feedback applied live to the underlying data.

PDF Slides Visualization
